# RUC Empirical IO Reading Group · Fall 2026

这是一个无需构建步骤的 GitHub Pages 静态网站。

## 发布到 GitHub Pages

1. 将当前文件夹推送至 GitHub 仓库（请同时提交 `papers_slides/` 中的 PDF 文件）。
2. 在仓库 **Settings → Pages** 中，将发布源设为 **Deploy from a branch**。
3. 选择包含本文件的分支（通常为 `main`）和根目录 `/ (root)`，然后保存。
4. GitHub 将提供网站链接；站点入口为 `index.html`。

所有站内 PDF 链接都以新标签页打开。新增一次报告时，可在 `index.html` 中复制一张 `.session` 卡片，并把相应 PDF 放入 `papers_slides/`。
